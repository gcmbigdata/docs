Una aplicación independiente puede involucrar varias capas dentro del servidor.

```mermaid
graph TD
    GitHub[GitHub Repository] --> Code["Código del Proyecto"]
    Code --> Storage["~/Documentos/projects/&lt;proyecto&gt;"]
    Storage --> Process["Proceso de Aplicación"]
    
    Process --> PM2["PM2"]
    Process --> Podman["Podman"]
    
    PM2 --> Nginx["Nginx (Reverse Proxy)"]
    Podman --> Nginx
    
    Nginx --> Domain["engine.clinicamedicos.com"]
    Domain --> User["Usuario Final"]

    style GitHub fill:#f0f0f0,stroke:#333
    style Storage fill:#e1f5fe,stroke:#01579b
    style Nginx fill:#dcfce7,stroke:#166534
    style User fill:#fef9c3,stroke:#854d0e
    style Process font-weight:bold
```

No todos los proyectos utilizan Podman. Su utilización depende de los requerimientos específicos de cada aplicación.

<Warning>
  Los nuevos desarrollos deben evaluar su incorporación dentro de **ATLAS** antes de crear una nueva infraestructura independiente.
</Warning>
