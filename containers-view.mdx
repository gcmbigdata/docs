Esta herramienta permite visualizar los contenedores administrados mediante Podman y proporciona mecanismos de monitorización y alertas.

## ¿Por qué es importante?

Algunos contenedores son dependencias críticas de determinadas aplicaciones.

Por ejemplo:

```text
Aplicación
│
├── PM2
│   └── Gestiona el proceso y mantiene la aplicación en ejecución
│
└── Contenedor Podman
    └── Proporciona el servicio requerido por la aplicación
```

Si el contenedor deja de estar disponible, la aplicación puede dejar de funcionar correctamente aunque su proceso PM2 continúe activo.

<Info>
  Por esta razón, **no basta con monitorizar únicamente PM2**. También debemos conocer el estado de los contenedores.
</Info>

## Alertas

Containers View permite establecer mecanismos de alerta para detectar cuándo un contenedor crítico deja de estar disponible.

Esto permite actuar rápidamente ante situaciones como:

- Contenedor detenido.
- Servicio que no inicia correctamente.
- Reinicio inesperado.
- Dependencia crítica fuera de servicio.

El objetivo es reducir el tiempo entre la aparición del problema y su detección.
